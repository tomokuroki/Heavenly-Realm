# Heavenly Realm

[English](README.md) · [Русский](README_RU.md)

**Heavenly Realm** — мод для NeoForge 1.21.1, превращающий смерть в путешествие по отдельному райскому измерению.

## Возможности

- Полностью собственное измерение Рая с тремя биомами
- Поля огромной анимированной травы, цветы и мирные животные
- Собственная 3D-модель ангела-хранителя с нимбом и анимированными крыльями
- Облачный мрамор, солнечный камень и небесные цветы с оригинальными текстурами
- Задание на сбор семи цветов для возвращения в обычный мир
- В Раю нельзя умереть, сбежать через пустоту или обычный портал
- Английская и русская локализация в игре

## Сборка

Требуется Java 21. Запустите `gradlew.bat build`. Готовый мод появится в `build/libs`.

Поддерживаются Minecraft 1.21.1 и NeoForge 21.1.250.
